  • ABOUT Ordinary Systems of a Well Established Language Library (OSWELL).

    The purpose of this application is to enhance user interaction with generative entities such as ChatGPT by providing an interactive avatar and direct access to realtime information such as current events, the weather, and much more through APIs. Furthermore, the user can modify the endpoints of the APIs, retrain the models used, redraw/customize the avatar in any way shape or form.

    The default input is "FACE" which utilizes the camera to detect human faces which the avatar will constantly follow. Another option is "MARKERS" which takes two blue colored objects, one on top of each other to control the avatar's movements. The last option is "SLIDERS" which does not rely on the camera, but rather manual movements of the avatar via mouse click on the sliders.

    The options for speed and gravity adjusts the avatar's movements in speed or weightlessness. The checkbox for debug allows the user to see behind the scenes that is involving the avatar's movements. The checkbox for speak moves the avatar's mouth as if speaking.
